# Support email triage: results

An LLM pipeline that reads customer support emails and returns category, sentiment, urgency and order ID as validated JSON for a dashboard.

- `index.html`: the approach, why it's reliable, the core function, and test results
- `dashboard.html`: the dashboard built from the pipeline's output

Data: real customer messages from the public "Customer Support on Twitter" dataset (Kaggle), turned into emails; names and order numbers are made up.
